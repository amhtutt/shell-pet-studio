    A few things to know

    Small crab.
    Fair questions.

    How often does my crab update?

    About hourly when someone views the badge. There is no background job. GitHub also caches README images, so changes can take longer to appear. The live preview shows when its activity data was fetched, when that information is available.

    Does it work with private repositories?

    No. Private repositories are never shown. Private and missing repositories return the same lost-egg badge and message, so a badge cannot tell them apart.

    Does this track my visitors?

    Studio adds no analytics or visitor tracking. Badges are images with no scripts. GitHub normally proxies README images; visiting Studio or an image URL directly still sends a normal web request to its host. No GitHub token or sign-in is needed here.

    Why does my crab look like this?

    The repository name deterministically seeds its body color, generic shell and decorations. Its main language selects a special shell when available. Stars choose its growth stage, contributor count adds decorations, and major releases add a little shell size. The same name produces the same traits; different repositories can share visible traits.

    Why is my crab in this mood?

    The first matching activity rule wins, in the order shown above. The live badge’s reason line explains the current result. Demo controls are for exploring expressions and never change the real repository’s mood.

    Can my crab get smaller or rest?

    Yes. Losing stars can move it back a stage. A repository with a crab rests when archived or after 180 days without commits: it naps inside its shell with a nightcap. A zero-star egg stays an egg.

    Is Save SVG a live badge?

    No. “Save frozen demo SVG” downloads the selected demo state as a snapshot. Use the copied Markdown for a badge that follows real repository activity.
