# Project provenance

The shell-pet application, CLI, tests, source artwork and references were merged from amhtutt/shell-pet commit 40965ad052356218ecb1edc4db679ca3c2598780. That commit and its history are retained as a merge parent in this repository.

The Studio interface remains the main homepage. The former shell-pet homepage, layout and stylesheet are preserved under reference/legacy-*; its live API, caching, CLI and art pipeline now use canonical root lib/ and svg/ modules. There are no duplicate src/lib/ or src/svg/ copies.
